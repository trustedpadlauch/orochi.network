Have questions about Orochi Network? Our FAQ section provides answers to common inquiries.

What is Orochi Network?

Orochi Network is the world’s first Verifiable Data Infrastructure, solving critical scalability, privacy, and data integrity challenges in blockchain ecosystems. Verifiable Data Infrastructure offers comprehensive features, including ZK-data-rollups, a Verifiable Data Pipeline, Hybrid aBFT Consensus, and a Merkle DAG

What are the main features of Orochi Network?

  1. Data Privacy: Ensures that data remains confidential.
  2. Security: Uses cryptographic techniques to protect data.
  3. Scalability: Can handle large volumes of data efficiently.
  4. Interoperability: Compatible with various data formats and systems.

What is ONACTIVE?

ONACTIVE lets anyone verify data for zkDatabase using just a browser, ensuring a secure, scalable, and decentralized data layer. Every verified code strengthens data integrity, contributing to the world’s first Verifiable Data Infrastructure—the backbone of AI, RWA, and the future internet. In return, verifiers earn $ON, Orochi’s governance token, fully unlocked after TGE.

How do I participate in building Orochi Network?

Orochi Network is a fully open source project, you can join us by joining our developer community at https://github.com/orochi-network
